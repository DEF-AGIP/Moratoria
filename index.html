¿Cómo poner esta página en GitHub y actualizarla con tu Excel?

Principio de funcionamiento:

Esta página web es 100% estática. Lee automáticamente el archivo data.csv (o data.xlsx) que está guardado en el mismo repositorio de GitHub. Cada vez que subas un Excel o CSV nuevo al GitHub, la página se actualiza automáticamente para todos los que la miren.

  1. Paso 1: Crear el repositorio en GitHub
    Creá un repositorio en GitHub (ej. tablero-moratoria) de tipo Público o Privado.
  2. Paso 2: Subir los archivos
    Subí a la raíz del repositorio los archivos: index.html, data.csv (o data.xlsx) y README.md.
  3. Paso 3: Activar GitHub Pages
    En tu repositorio vas a Settings > Pages. En Build and deployment > Branch seleccionás la rama main (raíz / (root)) y hacés clic en Save. ¡En 1 minuto tu página estará online en https://tu-usuario.github.io/tu-repo/!
  4. Paso 4: ¿Cómo actualizar los datos en el futuro?
    Cada vez que saques un reporte nuevo de la moratoria:
    • Podés reemplazar el archivo data.csv o data.xlsx directamente en la web de GitHub (botón Add file > Upload files).
    • Al confirmarlo (Commit), la página web cargará los nuevos números de inmediato al refrescar.

Origen del archivo de datos

Por defecto, la página busca el archivo data.csv (o data.xlsx) en la misma carpeta. También podés indicarle una URL remota de GitHub Raw:

Ejemplo: ./data.csv o https://raw.githubusercontent.com/usuario/repo/main/data.csv
